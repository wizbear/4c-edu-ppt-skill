---

## 🌟 Claude Web의 장점

### ✅ 다른 AI 대비 장점

**vs Gemini:**
- ✅ 형식 준수 훨씬 우수
- ✅ 긴 컨텍스트 (200K 토큰)
- ✅ Projects 기능으로 자동화

**vs ChatGPT:**
- ✅ 형식 준수 동등 또는 더 좋음
- ✅ Artifacts로 Markdown 미리보기
- ✅ 더 세밀한 수정 가능

**vs Claude Code:**
- ❌ 파일 저장은 수동
- ❌ 스크립트 실행은 별도
- ✅ 웹에서 어디서나 접근

---

## 🚀 사용 방법 (두 가지)

### 방법 1: 일반 채팅 (빠른 시작)
```
장점: 즉시 시작, 설정 불필요
단점: 매번 프롬프트 입력

```

단점: 초기 설정 5분 필요
소요: 초기 15분 → 이후 5-10분
```

```

# 모듈 [번호]: [제목]

## Module Start
[모듈 소개]

## Connect
time: [분]
title: [제목]
main: [주요 메시지]
sub: [부가 설명]

## Concept
time: [분]
title: [제목]
main: [핵심 개념]
sub: |
  - [포인트 1]
  - [포인트 2]

## Concrete Practice
time: [분]
title: [제목]
main: [실습 설명]
activity: |
  1. [단계 1]
  2. [단계 2]

## Conclusion
time: [분]
title: [제목]
main: [요약]
sub: [다음 학습]

## Break

⚠️ 매우 중요:
- 필드명(time:, title:, main:, sub:, activity:)을 절대 바꾸지 마

- sub: 또는 activity: 에서 여러 줄일 때 | 사용

이해했으면 "네, 이해했습니다"라고만 답해줘.

## 🚨 주의사항

### 무료 vs 유료

**Claude Free:**
- 제한적 사용 (하루 몇 개 대화)
- Projects 사용 불가
- 긴 대화 제한

**Claude Pro ($20/월):**
- 무제한 사용
- Projects 무제한
- 우선 접근
- 더 긴 컨텍스트

**권장:** 본격 사용 시 Pro 구독

---

### 파일 저장 주의

**반드시:**
- ✅ 확장자 `.md`
- ✅ 인코딩 UTF-8
- ✅ Artifacts "Copy" 버튼 사용

**하지 말 것:**
- ❌ 대화 내용 복사 (형식 깨짐)
- ❌ 스크린샷 (텍스트 아님)
- ❌ ANSI 인코딩 (한글 깨짐)

## 📞 문제 해결

### 문제 1: Projects가 안 보임

**원인:** Claude Free 사용
**해결:** Claude Pro 구독 또는 일반 채팅 사용

---

### 문제 2: Artifacts가 안 나타남

**원인:** 설정 문제
**해결:**
```
Settings → Features → Artifacts 켜기
```

---

### 문제 3: 형식을 안 지킴

**해결:**
```
⚠️ 다시 작성해줘.
반드시 이 형식을 정확히 지켜:

time: 3분
title: [제목]
main: [내용]
sub: [내용]

필드명을 절대 바꾸지 마!
```
