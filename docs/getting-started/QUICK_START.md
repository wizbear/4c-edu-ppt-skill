## 📝 AI 프롬프트 템플릿

### 초기 컨텍스트 설정
```
나는 "[과정명]" 교육 과정을 만들고 있어.

## 기본 정보
- 대상: [학습자]
- 목표: [학습 목표]
- 총 시간: [시간]

## 톤앤매너
- [친근한/전문적인]
- [실무 중심/이론 중심]

앞으로 각 모듈의 내용을 단계별로 요청할 거야.
일관성 있게 작성해줘.
```

### Connect 생성
```
모듈 [번호] "[제목]"의 Connect 단계를 작성해줘.

## 요구사항
- [연결할 경험]
- [사용할 질문]
- [제시할 사례]

## 출력 형식
## Connect
time: [분]
title: [제목]
main: [주요 메시지]
sub: [부가 설명]
```

### 한번에 생성 (2번째 과정부터)
```
모듈 [번호] "[제목]"의 Connect, Concept, Practice, Conclusion을
한번에 작성해줘.

위 Markdown 형식을 정확히 지켜서.
```

## ⚠️ 흔한 실수 방지

### ❌ 실수 1: 형식 오류
```markdown
# 잘못됨
time: 3
title 학습자와 연결

# 올바름
time: 3분
title: 학습자와 연결
```

### ❌ 실수 2: 시간 부족
- 실습 시간을 충분히 (10분 이상)
- 여유 시간 10% 확보

### ❌ 실수 3: 검토 생략
- 반드시 실습을 직접 해보기
- 체크리스트 사용

### ❌ 실수 4: 백업 안 함
- 항상 원본 파일 백업
- 클라우드에도 업로드
