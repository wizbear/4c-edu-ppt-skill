---

## 🎯 전체 프로세스 개요

```
Step 1: 구조 설계 (30분)
   ↓
Step 2: AI로 내용 생성 (1-2시간)
   ↓
Step 3: 내용 검토 (1-2시간)
   ↓
Step 4: 정리 및 PPT 생성 (30분)
   ↓
Step 5: 최종 검증 및 배포 (30분)
```

**총 소요 시간**: 3-5시간 (모듈 3-5개 기준)

---

## 📐 Step 1: 구조 설계 (30분)

### 목표
교육의 골격을 먼저 설계하여 명확한 방향 설정

### 작업
1. **구조 템플릿 복사**
   ```bash
   cp templates/structure_template.md 내_과정_구조.md
   ```

2. **기본 정보 입력**
   - 과정명, 대상, 총 시간
   - 학습 목표 3-5개

3. **모듈 구성**
   - 각 모듈의 주제 결정
   - 시간 배분 계획
   - 4C 각 단계의 목적 명시

### 산출물
- `[과정명]_구조.md` 파일
- 시간 배분 스프레드시트 (선택)

### 체크포인트
- [ ] 학습 목표가 측정 가능한가?
- [ ] 시간 배분이 현실적인가?
- [ ] 모듈 간 연결이 논리적인가?

## 🤖 Step 2: AI로 내용 생성 (1-2시간)

### 전략: 단계별 생성 (권장)

#### Option A: 단계별 생성 (품질 우선)
```
모듈 1 → Module Start → 검토 → OK
      → Connect → 검토 → OK
      → Concept → 검토 → OK
      → Practice → 검토 → OK
      → Conclusion → 검토 → OK

모듈 2 → (반복)
```

**장점**: 높은 품질, 수정 용이
**단점**: 시간 소요

#### Option B: 모듈별 생성 (속도 우선)
```
모듈 1 전체 → 검토 → 수정
모듈 2 전체 → 검토 → 수정
```

**장점**: 빠른 진행
**단점**: 대량 수정 가능성

### 프롬프트 사용
```bash
# 단계별 프롬프트 참고
cat templates/phased_prompt.md

# AI 콘텐츠 프롬프트 참고
cat AI_CONTENT_PROMPT.md
```

### 작업 팁
1. **컨텍스트 유지**: 같은 AI 대화창에서 계속 작업
2. **예시 제공**: "이런 스타일로" 예시 보여주기
3. **즉시 검토**: 생성되면 바로 확인
4. **점진적 개선**: 완벽보다는 빠른 반복

### 산출물
- 각 모듈의 Markdown 콘텐츠 (임시)

---

## ✅ Step 3: 내용 검토 (1-2시간)

### 검토 순서

#### 1단계: 형식 검증 (10분)
```bash
# 체크리스트 사용
cat templates/review_checklist.md
```

- Markdown 구조 확인
- 필수 필드 확인
- 시간 형식 통일

#### 2단계: 교육 품질 검증 (40분)
각 4C 단계별로:
- Connect: 공감, 호기심, 관련성
- Concept: 명확성, 정확성, 이해도
- Practice: 실행 가능성, 구체성
- Conclusion: 요약, 연결

#### 3단계: 전문성 검증 (20분)
- 내용 정확성
- 용어 일관성
- 예시 적절성

#### 4단계: 대상자 적합성 (20분)
- 난이도
- 언어 수준
- 관심사

#### 5단계: 흐름 검증 (10분)
- 모듈 간 연결
- 단계 간 연결

### 수정 방법

**작은 수정**: AI에게 재요청
```
이 부분을 다음과 같이 수정해줘:
[구체적 요청]
```

**중간 수정**: 직접 편집
```
Markdown 파일을 열어서 직접 수정
```

**큰 수정**: 재생성
```
이 모듈을 완전히 다시 작성해줘.
이번에는 [새로운 방향]으로.
```

### 산출물
- 검토 완료된 Markdown 파일

## 📝 Step 4: 정리 및 PPT 생성 (30분)

### 4-1: 최종 정리 (10분)

#### 형식 통일
- [ ] 모듈 번호 순차적
- [ ] 시간 형식 일관
- [ ] 들여쓰기 정확

#### 내용 통일
- [ ] 용어 통일
- [ ] 톤앤매너 일관
- [ ] 존댓말/반말 통일

#### 파일 저장
```bash
# 최종 파일명
[과정명]_[날짜]_v1.0.md

# 예시
Python기초_2026-01-06_v1.0.md
```

### 4-2: PPT 생성 (5분)

```bash
python .claude/skills/4c-edu-ppt/scripts/generate_with_master_layout.py \
  --md "Python기초_2026-01-06_v1.0.md" \
  --template "26-01-06_my_template.pptx" \
  --output "Python기초_최종.pptx"
```

### 4-3: 1차 검증 (15분)

PowerPoint 열어서:
- [ ] 슬라이드 수 확인
- [ ] 레이아웃 적용 확인
- [ ] 텍스트 채워짐 확인
- [ ] 텍스트 넘침 없음

### 산출물
- 최종 PPT 파일

## 🚨 문제 해결

### 문제 1: AI가 형식을 안 지킴
**해결**: 프롬프트에 형식 명시 강화
```
⚠️ 반드시 다음 형식을 정확히 지켜주세요:
[형식 예시]
```

### 문제 2: 내용이 너무 일반적
**해결**: 구체적 예시 요청
```
더 구체적으로 작성해줘:
- 실제 사례 포함
- 수치나 통계 추가
- [대상자]가 공감할 만한 상황
```

### 문제 3: PPT 생성 오류
**해결**:
1. Markdown 형식 재확인
2. 템플릿 레이아웃 확인
3. 스크립트 로그 확인

### 문제 4: 시간 부족
**해결**:
1. 구조를 더 단순하게
2. AI에게 한번에 더 많이 요청
3. 검토 기준을 완화 (v1.0)
