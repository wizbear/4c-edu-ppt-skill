# AI 생성 콘텐츠 검토 체크리스트

> AI가 생성한 교육 콘텐츠를 검토할 때 사용하세요.
> 체크리스트를 통과해야 다음 단계로 진행합니다.

---

## 📋 1단계: 형식 검증 (5분)

### Markdown 구조
- [ ] `# 모듈 [번호]:` 형식이 맞는가?
- [ ] `## Module Start` 있는가?
- [ ] `## Connect`, `## Concept`, `## Concrete Practice`, `## Conclusion` 모두 있는가?
- [ ] `## Break` 있는가?

### 필드 검증
각 4C 단계마다:
- [ ] `time:` 필드가 있는가?
- [ ] `title:` 필드가 있는가?
- [ ] `main:` 필드가 있는가?
- [ ] `sub:` 또는 `activity:` 필드가 있는가?

### 시간 형식
- [ ] `time: 3분` 형식인가? (숫자 + 분)
- [ ] 총 시간 합계가 계획과 맞는가?

---

## 🎯 2단계: 교육 품질 검증 (15분)

### Connect 단계
- [ ] **공감**: 학습자가 공감할 수 있는 상황인가?
- [ ] **호기심**: 다음 내용이 궁금해지는가?
- [ ] **관련성**: 주제와 직접적으로 연결되는가?

**수정 필요 시:**
```
이 Connect 내용을 수정해줘:
- 더 구체적인 사례로 변경
- [대상자]가 실제로 겪는 상황으로
- 질문을 더 흥미롭게
```

### Concept 단계
- [ ] **명확성**: 개념이 한 문장으로 설명되는가?
- [ ] **정확성**: 전문적으로 정확한 내용인가?
- [ ] **이해도**: 대상자 수준에 맞는가?
- [ ] **구조**: 불릿 포인트 3-5개인가?

**수정 필요 시:**
```
이 Concept 내용을 수정해줘:
- [전문 용어]를 더 쉽게 설명
- 비유를 추가해서 이해하기 쉽게
- 불릿 포인트를 [개수]개로 조정
```

### Concrete Practice 단계
- [ ] **실행 가능**: 실제로 할 수 있는 활동인가?
- [ ] **구체성**: 단계가 명확하게 서술되었는가?
- [ ] **시간**: 제시된 시간 내에 완료 가능한가?
- [ ] **난이도**: 학습한 내용을 적용할 수 있는 수준인가?

**실행 가능성 테스트:**
```
스스로 해보기:
1. 실습 단계를 직접 따라해본다
2. 막히는 부분이 있는가?
3. 추가 설명이 필요한가?
```

**수정 필요 시:**
```
이 Practice 내용을 수정해줘:
- [단계 번호]를 더 세분화
- 예상 결과를 각 단계마다 추가
- 난이도를 [쉽게/어렵게] 조정
```

### Conclusion 단계
- [ ] **요약**: 핵심 내용이 잘 정리되었는가?
- [ ] **성취감**: 배운 것을 명확히 인식하는가?
- [ ] **연결**: 다음 모듈로 자연스럽게 이어지는가?

**수정 필요 시:**
```
이 Conclusion 내용을 수정해줘:
- 배운 내용을 3개 포인트로 요약
- 다음 모듈과의 연결을 더 명확하게
```

---

## 🎓 3단계: 전문성 검증 (10분)

### 내용 정확성
- [ ] 사실관계가 정확한가?
- [ ] 최신 정보인가?
- [ ] 출처가 필요한 통계나 데이터는?

### 용어 일관성
- [ ] 같은 개념을 다른 용어로 표현하지 않았는가?
- [ ] 전문 용어 사용이 일관되는가?

### 예시 적절성
- [ ] 예시가 한국 상황에 맞는가?
- [ ] 저작권 문제가 없는가?
- [ ] 특정 집단을 차별하지 않는가?

---

## 👥 4단계: 대상자 적합성 검증 (10분)

### 난이도
- [ ] 너무 쉽지 않은가?
- [ ] 너무 어렵지 않은가?
- [ ] 사전 지식 요구사항이 맞는가?

### 언어 수준
- [ ] 대상자가 이해할 수 있는 언어인가?
- [ ] 전문 용어가 과도하지 않은가?
- [ ] 문장이 너무 길지 않은가?

### 관심사
- [ ] 대상자가 관심 가질 만한 주제인가?
- [ ] 실무/실생활에 적용 가능한가?

---

## ⏱️ 5단계: 시간 검증 (5분)

### 시간 배분
각 모듈:
- [ ] Connect: 2-5분 적절한가?
- [ ] Concept: 5-10분 적절한가?
- [ ] Practice: 10-20분 적절한가?
- [ ] Conclusion: 2-5분 적절한가?

### 총 시간
- [ ] 계획된 총 시간과 일치하는가?
- [ ] 휴식 시간이 포함되었는가?
- [ ] 여유 시간이 있는가? (10-15% 버퍼)

---

## 🔄 6단계: 흐름 검증 (10분)

### 모듈 간 연결
- [ ] 모듈 1 → 모듈 2 연결이 자연스러운가?
- [ ] 난이도가 점진적으로 증가하는가?
- [ ] 이전 내용을 활용하는가?

### 4C 단계 간 연결
각 모듈 내에서:
- [ ] Connect → Concept 연결이 자연스러운가?
- [ ] Concept → Practice 연결이 자연스러운가?
- [ ] Practice → Conclusion 연결이 자연스러운가?

## ✏️ 수정 작업 패턴

### 작은 수정 (AI에게 재요청)
```
[섹션]의 [부분]을 다음과 같이 수정해줘:
- [구체적 요청]
```

### 큰 수정 (직접 편집)
- Markdown 파일을 직접 열어서 수정
- 특히 전문 지식이 필요한 부분

### 재생성 (처음부터)
```
이 모듈의 [단계]를 완전히 다시 작성해줘.
이번에는 [새로운 방향]으로.
```

## 📊 품질 점수 계산

각 체크리스트 항목 = 1점

- **90점 이상**: 우수, 바로 사용 가능
- **70-89점**: 양호, 일부 수정 필요
- **50-69점**: 보통, 상당한 수정 필요
- **50점 미만**: 재생성 권장

## 💡 검토 팁

### 1. 프린트해서 검토
화면보다 종이로 보면 오류를 더 잘 발견

이상한 문장이나 흐름을 쉽게 파악

### 3. 동료 검토

### 4. 시간차 검토
생성 직후가 아닌 하루 뒤 다시 보기

### 5. 대상자 테스트
실제 학습자 1-2명에게 미리 보여주기

## 🚨 자주 발견되는 문제

### ❌ 문제 1: 너무 일반적인 내용
**증상**: "중요합니다", "필요합니다" 같은 추상적 표현
**해결**: 구체적 예시나 수치 요청

### ❌ 문제 2: 단계가 불명확
**증상**: "적절히 수정하세요", "잘 정리하세요"
**해결**: "정확히 어떻게"를 명시하도록 요청

### ❌ 문제 3: 난이도 급상승
**증상**: 갑자기 어려운 개념 등장
**해결**: 중간 단계 추가 요청

### ❌ 문제 4: 문화적 부적절
**증상**: 한국과 맞지 않는 예시 (달러, 미국 사례 등)
**해결**: 한국 상황에 맞는 예시로 변경 요청
