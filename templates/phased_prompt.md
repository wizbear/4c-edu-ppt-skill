# 단계별 AI 콘텐츠 생성 프롬프트

> 전체를 한번에 생성하면 품질이 떨어질 수 있습니다.
> 단계별로 나눠서 생성하고 검토하세요.

---

## 🎯 Phase 1: 모듈 1 개요만 생성

```
다음 구조에 맞춰 "모듈 1: [제목]"의 개요를 작성해주세요.

## 기본 정보
- 주제: [주제]
- 대상: [학습자]
- 시간: [분]

## Module Start만 작성
모듈 시작 인사와 개요를 2-3문장으로 작성해주세요.
```

**👀 검토 포인트:**
- 모듈 소개가 흥미로운가?
- 학습 동기를 부여하는가?

---

## 🎯 Phase 2: Connect 단계만 생성

```
모듈 1의 Connect 단계를 작성해주세요.

## 요구사항
- 학습자: [대상]
- 연결할 주제: [주제]
- 사용할 질문이나 사례: [미리 계획한 내용]

## 출력 형식
## Connect
time: 3분
title: [제목]
main: [질문 또는 주요 메시지]
sub: [구체적 예시나 사례]
```

**👀 검토 포인트:**
- 학습자가 공감할 수 있는가?
- 질문이 호기심을 유발하는가?
- 예시가 이해하기 쉬운가?

---

## 🎯 Phase 3: Concept 단계만 생성

```
모듈 1의 Concept 단계를 작성해주세요.

## 요구사항
- 핵심 개념: [가르칠 개념]
- 난이도: [초급/중급/고급]
- 설명 방식: [비유/예시/도식]

## 출력 형식
## Concept
time: 5분
title: [제목]
main: [핵심 개념 한 문장]
sub: |
  - [포인트 1]
  - [포인트 2]
  - [포인트 3]
```

**👀 검토 포인트:**
- 개념이 명확하게 설명되었는가?
- 전문 용어가 적절히 풀어졌는가?
- 불릿 포인트가 3-5개 적정인가?

---

## 🎯 Phase 4: Practice 단계만 생성

```
모듈 1의 Concrete Practice 단계를 작성해주세요.

## 요구사항
- 실습 내용: [무엇을 할 것인가]
- 실습 유형: [따라하기/문제풀이/프로젝트]
- 소요 시간: [분]

## 출력 형식
## Concrete Practice
time: 10분
title: [제목]
main: [실습 설명]
activity: |
  실습:
  1. [단계 1]
  2. [단계 2]
  3. [단계 3]
```

**👀 검토 포인트:**
- 실습이 실행 가능한가?
- 단계가 명확한가?
- 시간 내에 완료 가능한가?
- 학습 목표와 연결되는가?

---

## 🎯 Phase 5: Conclusion 단계만 생성

```
모듈 1의 Conclusion 단계를 작성해주세요.

## 요구사항
- 요약할 내용: [모듈에서 배운 것]
- 다음 모듈 주제: [모듈 2 주제]

## 출력 형식
## Conclusion
time: 2분
title: [제목]
main: [요약 내용]
sub: [다음 학습 예고]
```

**👀 검토 포인트:**
- 핵심이 잘 요약되었는가?
- 다음 모듈로 자연스럽게 연결되는가?

---

## 🔄 모듈 2, 3... 반복

각 모듈마다 위 Phase 1-5를 반복합니다.

**장점:**
- 각 단계 품질 관리
- 수정이 쉬움
- 일관성 유지
- 피로도 감소
