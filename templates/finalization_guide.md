## 📝 Step 4-1: 최종 Markdown 파일 정리

### 체크리스트

#### 형식 통일
- [ ] 모든 모듈 번호가 순차적인가?
- [ ] `time:` 형식이 일관되는가? (예: "3분", "10분")
- [ ] 들여쓰기가 올바른가?

#### 내용 일관성
- [ ] 용어가 통일되었는가?
- [ ] 톤앤매너가 일관되는가?
- [ ] 존댓말/반말이 통일되었는가?


## 🚀 Step 4-3: PPT 생성

### 빌드 전 검증 (필수)
```bash
python .claude/skills/4c-edu-ppt/scripts/validate_markdown_v3.py \
  --md "Python기초과정_2026-01-06_v1.0.md" \
  --report "Python기초과정_진행표.md"
```
- `[FAIL]` 이면 error를 고친다 (형식 문제, 빌드가 깨짐)
- warning은 설계 권고. `review_checklist.md` 2단계로 판정
- `--report` 로 저장된 진행표는 강사 노트와 함께 배포

### 기본 생성
```bash
python .claude/skills/4c-edu-ppt/scripts/generate_with_master_layout.py \
  --md "Python기초과정_2026-01-06_v1.0.md" \
  --template "26-01-06_my_template.pptx" \
  --output "Python기초과정_최종.pptx"
```

### 출력 확인
생성 후 콘솔 메시지 확인:
- `[SUCCESS] PowerPoint file created` 나왔는가?
- 총 슬라이드 수가 맞는가?
- 경고 메시지가 없는가?

## 🔍 Step 4-4: 생성된 PPT 검증

### 1차 검증: 구조 확인 (5분)

PowerPoint를 열어서:

#### 슬라이드 수
- [ ] 예상한 슬라이드 수와 맞는가?
- [ ] Module Start, Break 슬라이드가 있는가?

#### 레이아웃 적용
- [ ] Connect 슬라이드가 Connect 레이아웃인가?
- [ ] Concept, Practice, Conclusion도 올바른가?

---

### 2차 검증: 내용 확인 (10분)

각 슬라이드마다:

#### 텍스트 채워짐
- [ ] 제목이 들어갔는가?
- [ ] Main 메시지가 들어갔는가?
- [ ] Sub 메시지가 들어갔는가?

#### 텍스트 넘침 확인
- [ ] 텍스트가 박스를 벗어나지 않는가?
- [ ] 글자 크기가 적절한가?
- [ ] 여백이 충분한가?

**문제 발생 시:**
```
Option 1: Markdown 수정
- 텍스트를 줄인다
- 불릿 포인트로 나눈다

Option 2: 템플릿 수정
- 텍스트 박스를 크게
- 글꼴 크기를 작게
```

---

### 3차 검증: 디자인 확인 (10분)

#### 일관성
- [ ] 슬라이드 간 스타일이 일관되는가?
- [ ] 색상이 조화로운가?
- [ ] 글꼴이 읽기 쉬운가?

#### 가독성
- [ ] 6미터 거리에서도 읽히는가? (프레젠테이션용)
- [ ] 색상 대비가 충분한가?
- [ ] 줄 간격이 적절한가?

## ✏️ Step 4-5: 후처리 (선택)

PowerPoint에서 직접:

### 추가할 수 있는 요소

#### 1. 이미지/아이콘
```
삽입 → 그림 / 아이콘
- Concept 슬라이드에 개념 도식
- Practice 슬라이드에 스크린샷
```

#### 2. 차트/도표
```
삽입 → 차트
- 통계 자료 시각화
- 프로세스 다이어그램
```

#### 3. 애니메이션 (신중히)
```
애니메이션 탭
- 불릿 포인트 순차 등장
- 과도한 애니메이션은 지양
```

#### 4. 슬라이드 노트
```
보기 → 노트
- 강사용 메모 추가
- 실습 답안 추가
```

## 📦 Step 4-6: 버전 관리

### 파일명 규칙
```
[과정명]_[날짜]_[버전]_[상태].pptx

예시:
Python기초_2026-01-06_v1.0_초안.pptx
Python기초_2026-01-06_v1.1_검토중.pptx
Python기초_2026-01-06_v2.0_최종.pptx
```

### 변경 이력 기록
`CHANGELOG.md` 파일 생성:
```markdown
# 변경 이력

## v2.0 (2026-01-06)
- 모듈 2 Concept 단계 예시 변경
- 모듈 3 Practice 난이도 하향
- 전체 디자인 템플릿 변경

## v1.1 (2026-01-05)
- 동료 검토 반영
- 오타 수정

## v1.0 (2026-01-04)
- 초안 완성
```

## 🎯 Step 4-7: 최종 배포 준비

### 파일 패키징
```
배포 폴더 구조:
Python기초과정_배포/
├── Python기초과정_최종.pptx      # PPT 파일
├── Python기초과정_강사노트.pdf    # 강사 가이드
├── 실습파일/                      # 실습 자료
│   ├── example1.py
│   └── example2.py
└── README.txt                     # 사용 안내
```

### README.txt 예시
```
[Python 기초 과정]

1. 과정 정보
   - 총 시간: 60분
   - 모듈 수: 3개
   - 대상: 프로그래밍 입문자

2. 파일 설명
   - Python기초과정_최종.pptx: 강의 슬라이드
   - 실습파일/: 실습에 사용할 코드 파일

3. 강의 순서
   - 모듈 1: 변수와 데이터 타입 (20분)
   - 휴식 (5분)
   - 모듈 2: 조건문 (20분)
   - 모듈 3: 반복문 (15분)

4. 준비 사항
   - Python 3.x 설치
   - 텍스트 에디터 또는 IDE
```
